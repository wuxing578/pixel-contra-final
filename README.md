Pixel Contra Final | 像素魂斗罗
这是一个基于 HTML5 Canvas 和 JavaScript 开发的复古像素风格横版射击游戏。

🎮 游戏特性 (Features)
经典射击体验：复刻《魂斗罗》核心玩法，包含跑、跳、射击等动作。

像素风 UI (HUD)：

实时分数系统：记录战斗表现。

动态生命值：视觉化血条显示，支持多条生命统计。

连击系统 (Combo)：独特的击杀反馈界面，带发光特效。

武器状态栏：实时显示当前武器类型及能量槽。

丝滑操作：支持键盘快捷键及移动端 UI 适配。

🛠️ 技术栈 (Tech Stack)
Language: JavaScript (ES6+)

Renderer: HTML5 Canvas API

Styling: CSS3 (包含 Flexbox 布局及渐变动效)

🚀 如何运行 (How to Run)
克隆或下载本项目到本地。

确保 index.html 与相关的资源文件（如图片、音效）位于同一目录下。

使用任意现代浏览器（推荐 Chrome 或 Edge）打开 index.html 即可开始。
